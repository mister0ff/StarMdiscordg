=====================================================================
  COMO CRIAR UM MOD (.stc) PARA O CUBOLÂNDIA
=====================================================================
Um mod é um arquivo ZIP renomeado para .stc. Estrutura:

  mods_teste.stc
  ├─ mod.cmd            (identidade do mod - obrigatório)
  ├─ pack.png           (logo do mod)
  ├─ item/              um .txt por item
  ├─ bloco/             um .txt por bloco
  ├─ entidade/          um .txt por mob
  ├─ modelo/            modelos de mobs
  ├─ receitas/          receitas da bancada
  ├─ script/            scripts (eventos e comandos)
  └─ textura/           PNGs (16x16 para itens/blocos)

Formato dos arquivos:  chave: valor   (aspas opcionais, vírgula no fim opcional,
várias chaves na mesma linha separadas por vírgula, comentário com # no início da linha ou //).
Ids sempre no formato  namespace:nome  (ex.: teste:item). Itens do jogo usam star:
(star:dirt, star:log, star:stick, star:planks, star:stone, star:coal, star:iron_ingot,
star:diamond, star:torch ... use /itens no chat para ver todos).

---------------------------------------------------------------------
1) mod.cmd
---------------------------------------------------------------------
  version: "1.0",
  name: "Mod Teste",
  description: "Meu primeiro mod",
  author: "Eduhh"
  namespace: "teste"        (opcional; padrão = nome do mod)

---------------------------------------------------------------------
2) item/meu_item.txt
---------------------------------------------------------------------
  nome: "Meu Item"
  id: "teste:item"
  textura: "textura/item/item"
  empilhavel: 64            (1 se tiver durabilidade)
  durabilidade: 200         (opcional)
  dano: 6                   (dano ao bater)
  ferramenta: picareta      (picareta | machado | pa | espada)
  nivel: 2                  (0 madeira, 1 pedra, 2 ferro, 3 diamante)
  velocidade: 5             (velocidade de quebra)
  quebra_blocos: true       (false = não quebra blocos)
  comida: 6                 (restaura fome; segure botão direito)
  ao_usar: title @s title "Usou!"      (comando; pode repetir a linha)
  ao_bater: say bateu
  ao_comer: heal @s

---------------------------------------------------------------------
3) bloco/rubi.txt   (ids de bloco: até 79 blocos por mundo)
---------------------------------------------------------------------
  nome: "Bloco de Rubi"
  id: "teste:rubi"
  textura: "textura/bloco/rubi"        (todas as faces)
  textura_topo: ...  textura_lado: ...  textura_baixo: ...   (opcionais)
  dureza: 3
  ferramenta: picareta
  nivel: 2                  (nível mínimo para dropar)
  drop: "teste:item"        ("nenhum" = não solta nada; padrão = o próprio bloco)
  drop_quantidade: 2
  luz: 12                   (0-15, bloco que ilumina)
  solido: true   opaco: true
  ao_quebrar: say quebrou rubi
  ao_colocar: say colocou rubi
  ao_clicar: say clicou (botão direito)

---------------------------------------------------------------------
4) entidade/slime.txt  (mobs)
---------------------------------------------------------------------
  nome: "Slime Verde"
  id: "teste:slime"
  vida: 12
  velocidade: 2.4
  hostil: true
  comportamento: melee      (passivo | melee | ranged | explosivo)
  dano: 2
  largura: 0.9  altura: 0.9
  queima_de_dia: false
  spawn: noite              (nunca | dia | noite | sempre)
  textura: "textura/entidade/slime"
  modelo: "modelo/slime"    (sem modelo = cubo com a textura)
  drop: star:apple 1 2 0.5  (id min max chance; pode repetir)
  ao_morrer: say slime morreu

---------------------------------------------------------------------
5) modelo/slime.txt   (caixas; medidas em pixels, 16 px = 1 bloco)
---------------------------------------------------------------------
  tamanho_textura: 32 16
  parte: corpo | tam: 12 12 12 | pos: 0 6 0 | uv: 0 0
  parte: perna1 | tam: 3 4 3 | pos: -3 2 0 | uv: 0 0 | anim: perna_a
  # pos = centro da caixa, a partir dos pés. Frente do mob = -Z.
  # uv = canto da caixa na textura (padrão Minecraft: topo/baixo, lados). "uv: todos" = textura inteira em cada face.
  # anim: perna_a | perna_b | braco_a | braco_b   pivo: x y z (opcional)

---------------------------------------------------------------------
6) receitas/meu_item.txt  (bancada)
---------------------------------------------------------------------
  resultado: "teste:item",
  quantidade: 1

  [x] [x] [x]
  [x] [y] [x]
  [x] [y] [x]

  x: "star:log",
  y: "star:stick"
  # estacao: bancada | fornalha | nenhuma     (padrão: bancada)
  # sem grade:  ingredientes: ["star:log*3", "star:stick"]
  Obs.: a receita aparece na lista da bancada com a grade no tooltip; o jogo usa as
  quantidades dos ingredientes (a forma não é obrigatória).

---------------------------------------------------------------------
7) script/boas_vindas.txt
---------------------------------------------------------------------
  player-spawn
  run: title @s title "Bem-vindo"
  run: give @s star:dirt 10

  before-hit
  if: item == star:dirt and sneaking
  cancel:
  else:
  set: damage = damage * 2
  end:

Estrutura: linha com o NOME DO EVENTO, depois instruções:
  run: <comando>     executa qualquer comando do chat. Use {expressão} no texto: say Oi {player}
  if: <cond> / elseif: <cond> / else: / end:
  set: nome = expressão     (altera variável do evento, ex. damage; ou cria variável global)
  wait: segundos            (não funciona dentro de before-*)
  repeat: n ... end:
  cancel:                   (cancela a ação nos eventos before-*)

Eventos:
  player-spawn, player-death, player-jump, player-sneak, player-eat, second (1x por segundo)
  before-hit / after-hit        (vars: entity, damage, item, crit)
  before-break / after-break    (vars: block, bx, by, bz)
  before-place / after-place    (vars: block, bx, by, bz)
  before-use / after-use        (vars: item)       interact (botão direito em bloco)
  before-damage / after-damage  (vars: damage, source = fall|starve|drown|player|generic)
  before-chat                   (var: message)
  entity-death                  (var: entity)
Variáveis sempre disponíveis: player, health, hunger, sneaking, sprinting, flying, creative,
  on_ground, x, y, z, day, time, item, world.
Condições: == != < > <= >= and or not + - * / %   e funções:
  has_item(id, n), count_item(id), random(), rand(a,b), randint(a,b), chance(p), min, max, abs,
  floor, round, sqrt, len, contains, upper, lower, is_day(), var(nome), block_at(x,y,z)

Criar comandos:
  comando: curar "cura o jogador"
  run: heal @s
  run: say {player} usou /curar com argumento {arg1}
  (args: arg1..arg9 e args)  -> usado no chat como /curar

Comandos do jogo (também usados em run:):
  /title @s title|subtitle|actionbar|clear <texto>   /say   /me   /kill [@s|@e[type=zombie]]
  /fill x1 y1 z1 x2 y2 z2 bloco [replace alvo|hollow]   /setblock x y z bloco
  /give [@s] id [qtd]   /clear   /tp x y z (aceita ~)   /spawn   /setworldspawn   /heal   /feed
  /gm c|s   /time set day|night|n   /summon mob [x y z]   /effect @s speed|jump|regeneration|resistance|slowness [seg]
  /particle crit|hurt|burst   /gamerule regra true|false   /list   /mods   /itens   /seed   /ajuda
Comandos só funcionam com "Comandos" ligado nas regras; em servidores, só o admin (X EDUHH X).

---------------------------------------------------------------------
Importar: Jogar > Mundos > Editar > Mods > Importar mod (.stc).
Só o dono do mundo (ou o admin no servidor) pode importar. Mods valem por mundo.
Se algo estiver errado, os avisos aparecem no chat ao entrar no mundo.
